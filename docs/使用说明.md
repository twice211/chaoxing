## 0. 一分钟看懂：它能做什么、不能做什么

**能帮你做的事**

| 场景 | 命令 | 效果 |
|---|---|---|
| 刷课 | `python main.py study --course 课程名` | 自动进入未完成章节，视频按 1.0 倍速真实播放，文档/PPT 真实停留，进度自动记录，中断后可续 |
| 练习题不会做 | `python main.py practice --course 课程名` | 识别单选/多选/判断/填空/简答，给出答案、解析、知识点、可信度与本地资料依据 |
| 错题整理 | `python main.py wrong list / drill / export` | 自动汇总错题、统计薄弱知识点、重练、导出 md/JSON/CSV，可为错题出强化题 |
| 资料检索 | `python main.py search 关键词 --ai` | 把课件/讲义/PPT/PDF 建成知识库，支持“第二章电路分析”“这个公式怎么用”式搜索 |
| 开卷期末考试 | `python main.py exam --course 课程名` | 侧边栏只读辅助：当前题 + AI 分析 + 课程依据 + 相似题 + 提交前确认清单 |

**绝对不会做的事（代码层面禁止，配置也打不开）**

- 不自动登录、不识别/绕过验证码、不代填账号密码
- 不自动勾选答案、不点击“提交答案”——**所有作答与提交由你本人完成**
- 不加速刷课（倍速被强制 ≤ 1.0）、不跳进度、不伪造挂机状态、不绕过切屏/后台暂停检测
- 不修改学习通服务器数据、不伪造学习或考试记录、不修改考试倒计时
- 不绕过教师设置的任何考试限制；页面或通知里出现“闭卷/禁止 AI”时，考试模式**自动关闭**

> 合规前提：本课程/本次考试**明确允许**开卷并允许 AI 辅助。请始终以学校、教师与学习通当次考试的具体规定为准。

## 2.5 日常只用一条命令：`go`（推荐）

学习通多数是**会话级 Cookie**：进程一退出登录态就没了。所以**不要**把流程拆成
`login` → `courses` → `sync` → `study` 四条命令（那会反复要你登录），而是用一条：

```powershell
python main.py go --course 改革开放史 --keep --limit 5
```

它会在这**一个进程里**连续完成：登录（只这一次）→ 同步章节目录 → 自动学习 5 项 → 汇总；
`--keep` 让窗口结束后不自动关闭（按回车才关），避免“窗口突然消失”。

**课程结构适配**：本工具支持三种小节链接形式，包括学习通部分课程把跳转函数挂在
`div.chapter_item` 上（`onclick="toOld(courseId, jobId, clazzid, 0)"`、没有真实链接）的情况，
章节归属按 `chapter_unit` 精确对应，任务点完成状态按页面「N个待完成任务点」判定。

**排障不用反复登录**：

```powershell
python main.py capture --course 改革开放史                       # 把真实页面存成文件
python main.py sync --course 3 --from-capture data\capture\<时间戳>_chapter_frame01.html   # 离线再解析
```

---

**登录不上或不想等了？** 步骤轨右侧有**「取消登录」**按钮：

- 平时是灰的；一旦开始等待你登录，它就变可点；
- 点一下立刻结束等待（不会卡在 900 秒），浏览器窗口保持打开，随时再点「1 登录」继续；
- 等待期间程序**不会刷新或跳转登录页**（以前会每 15 秒跳去核验，把正在填的表单刷掉，这是“怎么都登录不上”的真正原因，已修复）；
- 同时小窗会自动挪到屏幕右侧并取消置顶，避免挡住浏览器登录窗口；登录成功后自动回到左上并恢复置顶。

## 3. 场景一：刷课（视频 / 文档 / PPT）

```powershell
python main.py study --course 电路                    # 处理全部未完成项
python main.py study --course 电路 --limit 10         # 本次最多 10 项
python main.py study --course 电路 --kinds video      # 只刷视频（document / ppt 同理）
python main.py study --course 电路 --practice         # 遇到测验/练习，顺带进入刷题辅助
python main.py study --course 电路 --no-kb            # 学习时不建知识库（更快）
python main.py study --course 电路 --all              # 忽略完成标记，从头重做
```

**你需要知道的规则**

1. **视频**：定位到播放器（支持嵌套在 iframe 里）→ 强制 1.0 倍速 → 每 10 秒读取真实进度并写库 → 播放到 `ended` 或进度 ≥98.5% 判定完成 → 自动进入下一项。
2. **窗口请保持前台**：学习通检测到页面切后台会暂停播放。程序发现停滞后最多尝试恢复 3 次，仍失败就记录“待人工”，**只提示你切回窗口，不伪造前台状态**。
3. **文档/PPT**：按正文字数决定停留时长，之后**以平台“已完成”标记为准**；标记读不到时要求你人工确认，程序绝不自行判定完成。
4. **断点续学**：每条完成后写入 `items.done`，同时记录 `resume` 游标；中途 `Ctrl+C` 或直接关窗口，下次运行 `study` 会自动从中断处继续。
5. **网络异常**：页面打不开自动按 1.5s → 3s → 6s 退避重试，超过 `MAX_RETRY_PER_ITEM` 次记录失败并跳过；整体循环还有步数与“无进展”双重保护，**不会死循环**。

## 4. 场景二：练习题不会做（刷题辅助）

```powershell
# 先把浏览器停留在练习/测验页面，或直接把页面地址贴给 --url
python main.py practice --course 电路
python main.py practice --course 电路 --url "https://mooc2-ans.chaoxing.com/..."
python main.py practice --course 电路 --limit 20
```

**每题输出格式（终端）**

```
──────────────────────────────────────────────────────────
第 3/12 题 ｜ 单选题
(单选题,2分)用戴维南定理求图示单口网络的等效电阻 R0 为( )
  A. 4Ω
  B. 6Ω
【答案】 A
【解析】 将独立源置零（电压源短路、电流源开路）后，两端看进去的电阻为 4Ω。
【知识点】戴维南定理；等效电阻
【所属章节】第二章 电路分析
【资料依据】[资料1]《第2章 等效变换》第12张幻灯片（formula）：Req = Uoc / Isc……
【可信程度】高

你在页面上选择的答案（回车=稍后自行处理，w=我答错了要进错题本，q=结束）:
```

**要点**

1. 程序**只分析不代答**：你在页面上自己勾选，自己点击“提交答案”。
2. 支持题型：单选、多选、判断、填空、简答（自动识别题号、题干、选项、分值、你已勾选的答案）。
3. **重复题检测**：题干指纹（忽略题号、标点、选项顺序）命中已有题目会提示“重复题”，还会做近似相似匹配（阈值 0.93）。
4. **判分结果回填**：你自己提交后进入“查看成绩/答题结果”页面，再次运行 `practice`，选“导入平台判分结果”，错题会自动进入错题库、答对的会累计正确次数。
5. **可信度机制**：题干歧义、图片题（AI 看不到图）、本地资料不足时，会明确标注“需要人工确认”，并在【资料依据】写“课程资料中没有找到直接依据”。**禁止编造来源是代码级校验**：AI 引用不存在的编号会被判定无效引用并自动降级。

## 4.5 直接问 AI 解析（最常用）

把题目贴给程序，立刻得到【答案】【解析】【知识点】【所属章节】【资料依据】【可信程度】：

```powershell
# 一行式
python main.py ask "（单选题）改革开放作为一场伟大革命，其性质是（ ） A. … B. … C. … D. …"

# 交互式粘贴（多行，连按两次回车结束）
python main.py ask

# 不写入本地题库
python main.py ask "题干…" --no-save
```

说明：
- 输出里的【资料依据】只会引用**你课程里真实抓到的内容**（如 `[资料1]《1.2 改革是社会主义制度的自我完善和发展》`）；
  本地没有依据时原样写"课程资料中没有找到直接依据"，AI 若引用不存在的编号会被判无效并降级为"需要人工确认"。
- 题目会自动进本地题库（`wrong list` 可查、`wrong drill` 可重练）。
- 需要先建知识库，依据才有内容：`python main.py kb build --course 课程名 --limit 20`

## 11. 常见问题（FAQ）

**Q1 会不会因为脚本访问被判定异常？**
程序内置操作间隔（默认 ≥1.2 秒）、失败退避与步数上限；不并发、不高频。请自行遵守学校与平台的使用要求。

**Q2 卡在“请在浏览器窗口完成登录”怎么办？**
在弹出的窗口里正常登录（含验证码/短信/扫码）。登录成功会自动继续；最长等待 15 分钟，可加大 `LOGIN_WAIT_TIMEOUT_SEC`。**程序不会代填账号或验证码。**

**Q3 `study` 里视频一直不动 / 学到一半停住？**
把浏览器窗口切回前台并保持（切后台会被平台暂停）；若反复停滞，程序会记录“待人工”，你可以手动播完再运行 `python main.py status` 核对。

**Q4 提示“没有识别到题目”或“目录抓不到”？**
多半是学习通前端改版。步骤：
1. `python main.py dump --url "页面地址"` 导出 HTML（含 iframe 内容）到 `data\dumps\`；
2. 在 HTML 里找稳定的 class/id（例如 `div.newQuestion`、`.question-title`）；
3. 在 `user_config.py` 追加：
```python
SELECTOR_OVERRIDES = {
    "question_root": ["div.newQuestion"],
    "question_stem": [".question-title"],
    "catalog_section": ["#newCatalog a"],
}
```
无需改动任何业务代码，重启命令即生效。

**Q5 错题本一直是空的？**
错题来自“判分导入”或练习中标 `w`。练习提交后进入**查看成绩/答题结果**页，再运行 `practice` 并选择导入判分结果。

**Q6 `search` 搜不到内容？**
先建库：`python main.py kb build --course 课程名`；本地笔记用 `kb local --dir 目录`。用 `kb docs` 看是否 `status=done`。

**Q7 AI 报错 429 / 超时 / 无输出？**
已自动重试（`AI_MAX_RETRY`）；仍失败可换更小上下文或更快的模型，或临时 `AI_ENABLE = False` 用纯本地检索。调用记录在 `ai_calls` 表。

**Q8 AI 给的答案能直接信吗？**
看【可信程度】：`高` 表示本地资料有直接依据；`中` 建议复核；`需要人工确认` 必须自己判断（常见于题干含图片、题面信息不完整）。程序会在 AI 引用了不存在的资料编号时**强制降级并提示**。

**Q9 `exam` 命令直接退出，提示 EXAM_MODE_ALLOWED？**
正常的安全行为。只有你确认本场考试允许开卷+允许 AI，才把该项设为 `True`，并按提示输入确认口令与课程名。

**Q10 终端中文乱码？**
程序启动会自动把控制台切到 UTF-8；仍乱码时执行 `chcp 65001`，或改用 Windows Terminal。

**Q11 侧边栏窗口出不来？**
用 `python main.py exam --course 课程名 --console` 走终端版。

**Q12 能同时处理多门课吗？**
可以。每条命令都用 `--course 课程名或id` 指定；`python main.py status` 会列出全部门课的完成百分比。

**Q13 换电脑怎么迁移？**
复制整个项目目录（含 `data\study_helper.db` 与 `data\browser_profile`）到新机器，安装 `requirements.txt` 与 `playwright install chromium` 即可；`user_config.py` 里的绝对路径注意同步修改。

## 12. 故障排查清单（按顺序检查）

1. `python --version` ≥ 3.11；
2. `python main.py selftest` 与 `btest` 全通过（不通过说明代码/依赖被改动）；
3. `python main.py login` 能看到浏览器窗口并成功登录；
4. `python main.py courses` 能列出课程（列不到 → 用 `dump` 校准选择器）；
5. `python main.py sync --course X` 后 `status` 中“学习项”不为 0；
6. `study` 期间窗口保持前台；
7. AI 相关异常看 `logs\study_helper.log` 与 `ai_calls` 表；
8. 页面结构问题用 `dump --url ...`，把 HTML 与报错一起反馈即可定位。
