绝对不会做的事（代码层面禁止，配置也打不开）

合规前提：本课程/本次考试明确允许开卷并允许 AI 辅助。请始终以学校、教师与学习通当次考试的具体规定为准。

3. 场景一：刷课（视频 / 文档 / PPT）

python main.py study --course 电路                    # 处理全部未完成项
python main.py study --course 电路 --limit 10         # 本次最多 10 项
python main.py study --course 电路 --kinds video      # 只刷视频（document / ppt 同理）
python main.py study --course 电路 --practice         # 遇到测验/练习，顺带进入刷题辅助
python main.py study --course 电路 --no-kb            # 学习时不建知识库（更快）
python main.py study --course 电路 --all              # 忽略完成标记，从头重做

你需要知道的规则

  1. 视频：定位到播放器（支持嵌套在 iframe 里）→ 强制 1.0 倍速 → 每 10 秒读取真实进度并写库 → 播放到 ended 或进度 ≥98.5% 判定完成 → 自动进入下一项。
  2. 窗口请保持前台：学习通检测到页面切后台会暂停播放。程序发现停滞后最多尝试恢复 3 次，仍失败就记录“待人工”，只提示你切回窗口，不伪造前台状态。
  3. 文档/PPT：按正文字数决定停留时长，之后以平台“已完成”标记为准；标记读不到时要求你人工确认，程序绝不自行判定完成。
  4. 断点续学：每条完成后写入 items.done，同时记录 resume 游标；中途 Ctrl+C 或直接关窗口，下次运行 study 会自动从中断处继续。
  5. 网络异常：页面打不开自动按 1.5s → 3s → 6s 退避重试，超过 MAX_RETRY_PER_ITEM 次记录失败并跳过；整体循环还有步数与“无进展”双重保护，不会死循环。

要点

  1. 程序只分析不代答：你在页面上自己勾选，自己点击“提交答案”。
  2. 支持题型：单选、多选、判断、填空、简答（自动识别题号、题干、选项、分值、你已勾选的答案）。
  3. 重复题检测：题干指纹（忽略题号、标点、选项顺序）命中已有题目会提示“重复题”，还会做近似相似匹配（阈值 0.93）。
  4. 判分结果回填：你自己提交后进入“查看成绩/答题结果”页面，再次运行 practice，选“导入平台判分结果”，错题会自动进入错题库、答对的会累计正确次数。
  5. 可信度机制：题干歧义、图片题（AI 看不到图）、本地资料不足时，会明确标注“需要人工确认”，并在【资料依据】写“课程资料中没有找到直接依据”。禁止编造来源是代码级校验：AI 引用不存在的编号会被判定无效引用并自动降级。

5. 场景三：错题整理与强化练习

python main.py wrong list                 # 待复习错题
python main.py wrong list --all           # 含已掌握
python main.py wrong stats                # 按知识点统计薄弱项
python main.py wrong drill --limit 10     # 错题重练（答对两次自动标记“已掌握”）
python main.py wrong export --fmt md      # 导出到 data\exports\（可选 json / csv）
python main.py wrong similar --id 12 --n 2 # 给第 12 题出 2 道同知识点强化题

题库字段（SQLite questions 表）：题目 → 选项 → 答案 → 解析 → 知识点 → 所属章节 → 错误次数 → 来源（平台判分/AI/人工）。

错题来源三条路

  1. 平台判分页只读导入（最准确，推荐考后/练习后执行）；
  2. 练习过程中你回答 w（“这题我错了”）即时入库；
  3. 练习时输入答案后由 AI 判分（仅练习场景，考试场景不做自动判分）。

7. 场景五：开卷期末考试 AI 辅助（默认关闭）

7.1 开启前必须满足的三重条件（缺一不可）

  1. 配置开关：在 user_config.py 里把 EXAM_MODE_ALLOWED 改成 True（代表你已确认本场考试允许开卷且允许 AI）。
  2. 许可依据：建议同时填写 EXAM_RULE_TEXT = "本课程期末考试为开卷考试，允许使用 AI 辅助"；若为空，程序会尝试从考试页面读取说明文字。两者都读不到明确许可时，会要求你粘贴教师/课程通知原文，且必须命中“开卷/允许使用 AI”等表述才放行（该文本作为 manual_grant 事件写入 exam_audit 表以便追溯）。
  3. 运行时二次确认：启动后逐字输入确认口令（默认 我已阅读并遵守考试规定）并填写课程名。

任何一步不满足，考试模式都不会启用。反过来，只要规则文本或页面出现“闭卷 / 禁止使用 AI / 不得查阅资料 / 独立完成”等表述，程序会自动关闭考试模式（运行中途也会持续复核）。

11. 常见问题（FAQ）

Q1 会不会因为脚本访问被判定异常？ 程序内置操作间隔（默认 ≥1.2 秒）、失败退避与步数上限；不并发、不高频。请自行遵守学校与平台的使用要求。

Q2 卡在“请在浏览器窗口完成登录”怎么办？ 在弹出的窗口里正常登录（含验证码/短信/扫码）。登录成功会自动继续；最长等待 15 分钟，可加大 LOGIN_WAIT_TIMEOUT_SEC。程序不会代填账号或验证码。

Q3 study 里视频一直不动 / 学到一半停住？ 把浏览器窗口切回前台并保持（切后台会被平台暂停）；若反复停滞，程序会记录“待人工”，你可以手动播完再运行 python main.py status 核对。

Q4 提示“没有识别到题目”或“目录抓不到”？ 多半是学习通前端改版。步骤：

  1. python main.py dump --url "页面地址" 导出 HTML（含 iframe 内容）到 data\dumps\；
  2. 在 HTML 里找稳定的 class/id（例如 div.newQuestion、.question-title）；
  3. 在 user_config.py 追加：
SELECTOR_OVERRIDES = {
    "question_root": ["div.newQuestion"],
    "question_stem": [".question-title"],
    "catalog_section": ["#newCatalog a"],
}

无需改动任何业务代码，重启命令即生效。

Q5 错题本一直是空的？ 错题来自“判分导入”或练习中标 w。练习提交后进入查看成绩/答题结果页，再运行 practice 并选择导入判分结果。

Q6 search 搜不到内容？ 先建库：python main.py kb build --course 课程名；本地笔记用 kb local --dir 目录。用 kb docs 看是否 status=done。

Q7 AI 报错 429 / 超时 / 无输出？ 已自动重试（AI_MAX_RETRY）；仍失败可换更小上下文或更快的模型，或临时 AI_ENABLE = False 用纯本地检索。调用记录在 ai_calls 表。

Q8 AI 给的答案能直接信吗？ 看【可信程度】：高 表示本地资料有直接依据；中 建议复核；需要人工确认 必须自己判断（常见于题干含图片、题面信息不完整）。程序会在 AI 引用了不存在的资料编号时强制降级并提示。

Q9 exam 命令直接退出，提示 EXAM_MODE_ALLOWED？ 正常的安全行为。只有你确认本场考试允许开卷+允许 AI，才把该项设为 True，并按提示输入确认口令与课程名。

Q10 终端中文乱码？ 程序启动会自动把控制台切到 UTF-8；仍乱码时执行 chcp 65001，或改用 Windows Terminal。

Q11 侧边栏窗口出不来？ 用 python main.py exam --course 课程名 --console 走终端版。

Q12 能同时处理多门课吗？ 可以。每条命令都用 --course 课程名或id 指定；python main.py status 会列出全部门课的完成百分比。

Q13 换电脑怎么迁移？ 复制整个项目目录（含 data\study_helper.db 与 data\browser_profile）到新机器，安装 requirements.txt 与 playwright install chromium 即可；user_config.py 里的绝对路径注意同步修改。
